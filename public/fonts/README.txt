Place the Segment7 font file in the segment7 folder.

From https://fontlibrary.org/en/font/segment7: download the zip, extract it,
and put the .otf file (e.g. Segment7Standard.otf) inside public/fonts/segment7/.

If the file has another name (e.g. Segment7.otf), rename it to Segment7Standard.otf
or update the path in src/styles/glow.css @font-face.
